# CardioGuard - Heart Disease Prediction

## Overview

CardioGuard is an AI-powered Heart Disease Prediction System developed using Machine Learning and Streamlit.

## Features

* Heart Disease Risk Prediction
* Heart Health Score
* Downloadable Report
* Random Forest Classifier
* Interactive Streamlit Dashboard

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn

## Model Performance

* Accuracy: 98.5%

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run Guard_ai.py
